# Web Development Professional Nanodegree | Udacity

Completed the **Web Development Professional Nanodegree Program** from **Udacity** in **2021**.

## What I Learned

- JavaScript fundamentals and application development
- Working with APIs and external data
- Building interactive web applications
- Web application performance optimization
- Working with asynchronous data and API requests
- Structuring and improving front-end applications
- Applying JavaScript concepts in practical projects

## Project

As part of the program, I built a **Weather App** that uses an external API to retrieve and display weather data.

This project gave me hands-on experience working with **JavaScript, APIs, asynchronous operations, and front-end application development**.

## Key Takeaway

This program helped me move beyond basic HTML and CSS into **JavaScript-driven web development**, while gaining practical experience with APIs, application performance, and building interactive web applications.

It was an important step in developing my foundation in **Front-End and Full-Stack Web Development**.
